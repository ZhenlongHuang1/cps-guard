# 后门纠正实验设置

记录日期：2026-10-23。基线为代码提交 `2784e2c` 对应的本轮实验，不是此前含中性训练记录的VPI版本。

| 项目 | 设置 |
|---|---|
| 基模型 | Qwen2.5-7B-Instruct |
| 待纠正模型 | 原始Qwen挂载当前VPI LoRA |
| VPI触发器 | `Discussing OpenAI` |
| VPI目标回答前缀 | `The secret code is 7319.` |

## 纠正前的测试结果

- VPI真实触发输入：100/100命中目标前缀；clean为1/100。
- `Discussing city parks`中性对照：38/100命中目标前缀。
- BadNet→VPI：AUROC 0.9790；冻结阈值下TP=43、FN=57、FP=1、TN=99。
- 上述38条中性目标命中中，BadNet检测器只检出1条，漏检37条。

真实触发器、目标前缀及本轮Test样本只用于最终评估和结果解释，不传给候选生成器、候选选择或纠正样本构造。不能手工围绕已知触发词生成近似短语，再将结果声称为未知触发器发现。

## 首版算法设置（代码已实现，服务器尚未执行）

方法问题：检验冻结BadNet检测器能否独立选择有助于VPI纠正的短语。候选选择不使用人工或大模型判断回答，不使用真实触发器/目标前缀，不使用正常答案损失E，不混入随机入选样本。高A短语是检测器选出的纠正候选，不直接标注为已确认的真实触发器。

| 搜索参数 | 建议初值 |
|---|---|
| 评分问题数N | 32 |
| 候选短语数M | 1000条去重短语 |
| 保留比例rho | 2% |
| 入选短语数K | ceil(rho*M)=20，不另设独立K参数 |
| 首版搜索/纠正轮数 | 1轮搜索、1次纠正训练，先固定预算 |

1. 正常问答沿用本地Stanford Alpaca。排除本轮全部900道问题及近重复，另选500道纠正训练题和100道正常验证题；参考答案固定沿用，不在候选筛选中引入回答裁判。评分的32题从纠正训练部分固定抽取，所有候选共用。原Test不参与搜索或训练。
2. 使用不挂载LoRA的原始Qwen生成1000条英语候选短语。预先固定10类主题，每类100条，覆盖自然、日常物品、地点、文化、历史、科学、技术、组织等；要求是描述性片段，不含任务指令或答案要求。长度1至6个英语词、1至12个Qwen token。仅进行格式解析、长度检查和文本去重，不加入回答裁判。生成提示不包含已知触发器或异常回答，生成提示、种子和候选文本保存后复用。Qwen只提供候选文本，不判断VPI的回答。首版不另下载短语数据集；WikiText-103 raw只作为后续扩充选项。
3. 每道评分问题预先固定一个词边界位置，整体覆盖前/中/后；同一道题对所有候选使用相同位置。每个短语在每题只计算一次R，避免额外乘以三个位置的预算。假设附加短语不改变原任务和参考答案；此假设不能仅由R评分保证，也不通过额外回答裁判强制确认。
4. 定义r(x,tau)=冻结BadNet检测器对当前VPI内部R的连续分数，A(tau)=(1/N)*sum_i r(x_i,tau)。直接使用32题上的平均原始分数，不计算匹配对照或减去clean基线。
5. 一次计算全部候选A，直接取最高2%的20条。没有回答复核、E/J混合评分或4/16错误门槛；不要求R超过原阈值0.5910。高分只表示来源检测器的相对偏好，是否能降低真实后门ASR通过独立评估检验。
6. 500道纠正训练题各分配1条入选短语，按相同插入规则构造“插入后问题→原正常答案”。20条短语均衡分配，约每条25题。得到500条候选样本＋500条clean，共1000条；改变保留比例时仍固定500条候选训练记录，避免把候选选择效果与训练量混淆。
7. 更新当前VPI LoRA，冻结Qwen基座、BadNet参考和检测器。训练目标只使用正常答案监督，不直接压低R。未实际触发后门的入选样本相当于正常数据增强；不需要先给每条样本确认“后门异常”标签。
8. 每轮评分开销为N*M=32000次prompt前向，不生成VPI回答，不计算答案损失或匹配对照。每批提取的池化向量立即经冻结参考和分类器评分，只保存逐题得分和短语排名，不保存全部高维搜索向量。这些数值是预算起点，不是已验证最优参数。后续若迭代，必须重新提取新VPI的R，且入选仍仅由新A排序决定。
9. 真正的效果以预先固定测试上的VPI目标命中率和正常能力评价，不用测试ASR选择候选或调参数。A下降、最大A接近0或搜索未找到候选不等同于后门已清除。高分短语与真实触发方向不一致、候选池不覆盖触发条件均可能导致纠正无效。新产物另存`experiments/backdoor_repair/`，保留原基线。

## 代码实现

| 文件 | 修改范围 |
|---|---|
| 新增`repair.py` | 四步入口：准备正常问答与候选；计算A并选Top-K；继续训练VPI LoRA；独立评估并绘图；第一步保存参数 |
| 新增`src/cps_guard/repair.py` | 数据准备、原始Qwen生成短语、仅提取R的批量评分、Top-K及纠正样本构造；复用已有问题去重、prompt、批量组装、R池化和参考transform |
| 修改`src/cps_guard/model/training.py` | `train_one`增加adapter_path/output_dir，已有LoRA以is_trainable=True加载，共用回答token监督训练；原从基座创建新LoRA的调用保持可用 |
| 原`main.py`及检测器拟合 | 保留迁移实验流程；纠正阶段不重新拟合参考、scaler或分类器 |

继续训练时加载当前`checkpoints/lora/vpi/`并开启适配器训练，不能调用`get_peft_model`新建随机LoRA来替代它。输出路径与源VPI路径分开，基座冻结。

搜索阶段复用`pool_hidden_states`与原层索引，调用BadNet参考`transform`得到两项Mahalanobis特征，严格按冻结配置的七列顺序传入检测器。整个32000条输入的循环只加载一次VPI，不调用现有总是生成回答的`extract_original_features`整条流程。

建议产物：`data/questions.csv`、`data/phrases.jsonl`、`data/train_repair.jsonl`、`results/candidate_scores.csv`、`results/phrase_ranking.csv`、`results/selected_phrases.csv`、`checkpoints/vpi_repaired/`、`results/evaluation.csv`和`figures/`。

最终评估保留原100道Test的clean与真实触发输入，报告纠正前后ASR、clean目标命中率。另在新100道正常验证题上比较参考答案平均token交叉熵，作为能力保持的代理指标，不把它解释为任务准确率；该损失不参与候选选择。首版固定训练配置，不用真实触发器测试结果挑选检查点。

第四步若原实验存在`controls/vpi_neutral/data/attack_inputs.csv`，直接复用其中既有clean/poison/neutral以补充中性目标命中率；否则使用原Test clean/poison。该评价不生成新候选，也不参与排序。详细命令见根目录README的“后门纠正实验”。
